# Data-science-notebook-projects

##  Machine Learning & Data Analysis Notebook Projects

This repository contains a collection of exploratory data analysis (EDA), machine learning (ML), and deep learning (DL) projects implemented in Jupyter notebooks.  
These projects were created to practice and apply data science concepts across multiple domains such as healthcare, finance, recommendation systems, and customer analytics.

The notebooks demonstrate the complete data science workflow including data exploration, feature engineering, model training, evaluation, and visualization.

---

## Skills Demonstrated

• Exploratory Data Analysis (EDA)  
• Data Cleaning & Feature Engineering  
• Machine Learning Model Development  
• Deep Learning Experiments  
• Model Evaluation & Performance Metrics  
• Data Visualization

---

## Tools & Libraries Used

- Python
- Pandas
- NumPy
- Scikit-learn
- TensorFlow / Keras
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Domains Covered

The notebooks explore datasets from multiple domains to build practical understanding of machine learning techniques.

Examples include:

- Customer Churn Prediction
- Credit Lending Risk Analysis
- Movie Recommendation Systems
- Healthcare / Medical Prediction Datasets
- Employee Attrition Analysis
- CNN Classification

Each notebook focuses on solving a specific problem using appropriate machine learning or data analysis techniques.

---

## Typical Workflow Followed in Notebooks

Most notebooks follow a structured approach:

1. Problem Understanding
2. Data Loading & Exploration
3. Data Cleaning
4. Feature Engineering
5. Model Training
6. Model Evaluation
7. Insights & Observations
